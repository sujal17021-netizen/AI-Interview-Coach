DATA STRUCTURES AND ALGORITHMS INTERVIEW KNOWLEDGE

1. Data Structures
Data structures organize and store data for efficient access and modification.

2. Array
An array stores elements in indexed positions. Access by index is generally O(1).

3. Linked List
A linked list contains nodes where each node stores data and a reference to another node.

4. Stack
A stack follows LIFO: Last In, First Out.
Operations: push, pop and peek.

5. Queue
A queue follows FIFO: First In, First Out.
Operations: enqueue and dequeue.

6. Hash Table
A hash table stores key-value pairs and uses a hash function to locate values.

7. Searching
Linear search checks elements one by one. Binary search works on sorted data.

8. Sorting
Common sorting algorithms include bubble sort, selection sort, insertion sort, merge sort and quicksort.

9. Big O Notation
Big O describes how an algorithm's time or space requirements grow with input size.
Examples: O(1), O(log n), O(n), O(n log n), O(n^2).
